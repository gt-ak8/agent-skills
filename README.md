# agent-skills

A small collection of agent skills.

## Install

The preferred way is via [`npx skills`](https://github.com/vercel-labs/skills):

```sh
# task-planner — write actionable plans to ~/.agentic/plans/
npx skills@latest add https://github.com/gt-ak8/agent-skills/tree/main/task-planner

# use-cmux — drive the local cmux app from inside a `cmux ssh` VM
npx skills@latest add https://github.com/gt-ak8/agent-skills/tree/main/use-cmux
```

Or install every skill from this repo at once:

```sh
npx skills@latest add gt-ak8/agent-skills
```
